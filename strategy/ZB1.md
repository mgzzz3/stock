# ZB1

ZB1 是独立于原 B1 的三持仓规则模拟，不继承原 B1 的固定到期退出或滚动门控，不连接实盘下单。

- 股票池：先在每日完整 `data/signals/b1_YYYYMMDD.csv` 中按去重股票数量统计行业，只选数量最多的行业，再与同日 `data/predictions/next_day_YYYYMMDD.csv` 取交集。行业数量并列第一时合并候选，行业缺失不参与统计；不使用预测文件中的行业或今日行业资料替代历史B1行业。
- 买入：在上述最多行业候选中，收盘后跳过已持有股票，按预测文件保存的排名取空位数量，最多三只；下一市场交易日开盘执行。可买候选不足时留现金，不跨到较少行业补足。缺失预测不补算、不交易。无有效开盘行情的委托当日失效，不推迟至个股复牌日。
- 仓位：初始资金分三份；补仓时现金按空位均分。不重复买入、不每日再平衡，不因为退出 B1 池或排名下降卖出。
- 止盈：持有收益**严格超过 15%**才激活保护，之后回落到 **10% 或以下**退出。这里的 10% 是相对买入成本的收益，不是从最高价回撤 10%。
- 止损：持有收益达到 **-5% 或以下**退出。除这两种条件外一直持有，包括回测结束时不强制平仓。
- 补仓：卖出当日收盘后仍先统计完整B1池的最多行业，再按行业内预测排名安排下一交易日开盘补充。统计行业数量时不剔除已持仓或无预测股票；选股时才跳过已持仓。满仓时不换仓，也不因最多行业发生变化卖出原持仓。

## 模拟口径

买入当日不卖出，但最高价可激活止盈。日线不能确定盘中顺序：尚未激活时同日同时触及止损与激活线，优先止损；否则同日激活并回撤按先高后低估算。已经激活的持仓，正常盘中下跌先经过 10% 退出线。

开盘跳空越过退出线时按开盘价成交，所以实际收益不保证等于 10% 或 -5%。停牌、零成交量、缺失有效行情时保留持仓及最后估值。通过 `pct_chg` 链式价格指数近似处理除权，阈值按除权持有收益计算；不是现金分红与送转股的完整账户记账。

模拟买卖各收取 0.10% 成本；触发阈值不扣手续费。净值包括现金及未平仓市值，交易胜率与净单笔收益只统计已卖出交易。尚未模拟涨跌停排队、滑点、整手限制和真实税费差异。

## 刷新与验证

每日现有 `daily.sh` 的 Web 导出步骤会自动重放 ZB1，保留从第一份可用预测起的连续持仓状态。它不是实际账户持仓记录；修改历史存档会改变模拟结果。

```bash
uv run python export_web_data.py --strategies-only
uv run python -m unittest discover -s tests -p 'test_zb1.py' -v
```

策略页展示当前持仓、持有收益、止盈激活状态、次日补仓、净值回撤及已完成交易。完整持仓、补仓和成交记录位于 `web/data/strategies.json` 中 `id=zb1` 的 `portfolio` 字段。
